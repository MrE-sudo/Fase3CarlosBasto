# Fase3CarlosBasto

Compensandote Family Compensation Fund - Affiliate control (stack, queue and list) with Tkinter.

- Run the app: `python main.py` (Python 3.10+). Password: `Caja`.
- Run the tests: `python -m unittest discover -s tests -v`
- Files: main.py, login_view.py, affiliation_view.py, models.py, config.py
- Documents: Abstraccion_Fase3CarlosBasto.docx, Evidencias_Pruebas_Fase3CarlosBasto.docx
- Test evidence: tests/evidence (screenshots and unit test output)
